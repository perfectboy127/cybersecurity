NIPE

NIPE is a tool used in these notes to route system traffic through Tor. The procedure covers cloning NIPE, installing dependencies, starting Tor, checking status, and restarting or stopping NIPE.

01

Open NIPE repository

https://github.com/htrgouvea/nipe ↗

Use: Opens the NIPE source-code repository on GitHub.

02

Open terminal as root

Use: Opens a terminal with administrator privileges.

03

Clone repository

git clone https://github.com/htrgouvea/nipe.git

Use: Downloads the project files from GitHub.

04

Open NIPE directory

cd nipe

Use: Moves into the NIPE project folder.

05

Install dependencies

cpanm --installdeps .

Screenshot shows the terminal offering to install cpanminus when cpanm is not found. Select Y, then repeat the command.

Use: Installs the Perl dependencies required by the project.

06

Repeat dependency installation

cpanm --installdeps .

Use: Runs the dependency installation again after the prerequisite is installed.

07

Start Tor and NIPE

service tor start
./nipe.pl start

Use: Starts the Tor service and then starts NIPE.

08

Check status

./nipe.pl status

Original status output shown in your notes:

[+] Status: true
[+] Ip: 192.42.116.99
View original screenshot (PDF page 3)

Use: Displays whether NIPE is active and the IP it reports.

09

Restart or stop NIPE

./nipe.pl restart
./nipe.pl stop

Use: Restarts or stops NIPE using its command-line controls.
