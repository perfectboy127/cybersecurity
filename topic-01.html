Tor on Browser

Your original notes, reorganized into readable steps with selected screenshots.

Tor is used in these notes with ProxyChains to route Firefox traffic through a local SOCKS5 proxy. The procedure covers installing Tor, configuring ProxyChains, checking IP and DNS results, and adjusting Firefox settings.

TOPIC 01

Installation

01

Update package list

apt update

Use: Refreshes the package information used by apt.

02

Install Tor

apt install tor

Use: Installs the Tor software package.

03

Install ProxyChains

apt install proxychains

Use: Installs the ProxyChains utility.

Start Tor and Firefox

Open terminal as root

13
